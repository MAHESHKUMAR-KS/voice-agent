## 📹 How to Film a DIY Demo Video

If you want a real demo video:

1. **Screen recording** (easiest):
   - Use OBS Studio (free) or Camtasia
   - Record yourself:
     - Type a FAQ question
     - Show the agent thinking (add pause)
     - Show the text response appearing
     - Show confidence score
   - Add voiceover
   - Duration: 3-5 seconds

2. **Phone recording** (quick):
   - Actually call the voice agent
   - Record the conversation
   - Add transcript overlay
   - Duration: 30-45 seconds (then trim to 5 sec highlight)

3. **Animated demo** (professional):
   - Use tools like Loom, Synthesia, or D-ID
   - Create a talking avatar
   - Sync with your voice script
