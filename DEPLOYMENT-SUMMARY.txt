HOW TO DEPLOY
================================================================================

OPTION 1: LOCAL TESTING (Recommended First)
──────────────────────────────────────────
  Terminal 1: cd backend && npm install && npm run dev
  Terminal 2: cd frontend && npm install && npm run dev
  Visit: http://localhost:9045

OPTION 2: DOCKER LOCAL
──────────────────────
  docker-compose up
  Visit: http://localhost:9045

OPTION 3: RAILWAY (Production - Recommended)
─────────────────────────────────────────────
  1. Sign up at railway.app
  2. Connect GitHub repo
  3. Set env variables:
     - NODE_ENV=production
     - CORS_ORIGIN=https://your-domain.com
  4. Deploy (automatic)

OPTION 4: MANUAL SERVER
───────────────────────
  1. Build: cd frontend && npm run build
  2. Build: cd backend && npm run build
  3. Deploy built files to server
  4. Set environment variables
  5. Run: npm start (from backend)
