EASIEST: Railway.app

1. Go to railway.app
2. Sign up with GitHub
3. Click "New Project"
4. Select "Deploy from GitHub"
5. Choose this repository
6. Set environment variables:
   NODE_ENV = production
   CORS_ORIGIN = https://your-domain-from-railway.app
   PORT = 9045

7. Click Deploy
8. Wait 2-3 minutes
9. Get your URL from Railway dashboard
10. Share with team! 🎉

ALTERNATIVE: Docker on Your Server

1. Build: docker build -t voice-rag .
2. Run: docker run -p 9045:9045 voice-rag
3. Visit: http://your-server:9045

================================================================================
TROUBLESHOOTING
================================================================================

Q: Form not submitting?
A: Check CORS_ORIGIN matches your frontend domain

Q: Demo video not playing?
A: Video file was included in build (should work automatically)

Q: Page shows 404?
A: Check backend is running and serving frontend

Q: Database not saving?
A: Check /app/data directory exists and is writable

Q: Can't run locally?
A: npm install dependencies first in both folders
